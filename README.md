# 🗂️ Team Task Manager (MERN Stack)

A full-stack Task Management Web Application built using the MERN stack that helps teams collaborate, assign tasks, and track progress with role-based access (Admin & Member).

## 🚀 Live Demo
- Frontend: https://your-frontend-link.com
- Backend: https://your-backend-link.com

## 📌 Features

### 👤 Authentication
- User Signup & Login
- JWT-based authentication
- Secure password handling

### 🧑‍💼 Role-Based Access
- Admin & Member roles
- Admin can manage users and tasks
- Members can view and update assigned tasks

### 📁 Task Management
- Create, update, delete tasks
- Assign tasks to users
- Set priority and due dates
- Track task status (To Do / In Progress / Completed)

### 📊 Dashboard
- Task overview
- Status tracking
- Recent tasks
- Progress visualization

### 👥 Team Management
- Add and manage users
- Assign tasks to multiple users

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit
- React Router
- Axios
- Tailwind CSS (or CSS)

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- REST APIs


Backend Setup
cd backend
npm install

Create .env file:

MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=8800

Run backend:

npm start
Frontend Setup
cd frontend
npm install
npm run dev

🔐 Environment Variables
Variable      	Description
MONGODB_URI   	MongoDB Atlas connection string
JWT_SECRET	    Secret key for authentication
PORT       	    Backend server port
